## 5. 設計への示唆

- **単価は「会社」単位ではなく「会社×車種（10t／4t等）」単位で持つ必要がある。** 元データの17行が車種違いの別料金であることからも明らか。ユーザー案の「現場ごとの単価」に車種の軸を追加するかどうかが、フェーズ2設計の論点の一つ（詳細は設計提案書参照）。
- 注記（4/2等の日付、国交省・Lゲート等のラベル）は「適用開始日」「備考」のどちらに寄せるべきか、意味が行によって違うため機械的な振り分けは避け、インポート時に人が確認して割り当てる運用を提案する。
- 金額を含まない2行（電話メモのみ）は自動インポート対象から除外し、単価未設定として登録する。
