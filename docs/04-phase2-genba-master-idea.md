# フェーズ2アイデアメモ：現場マスター機能

**このドキュメントは設計アイデアの記録です。フェーズ1完成前は実装しません。** フェーズ1（出欠札のデジタル化＋Windows PCでの試験運用）が完了し、フェーズ2に着手するタイミングで、この内容をベースに改めて設計・承認プロセスを行います。

## 発想のきっかけ

以前の別プロジェクト（Excel版トラック配車システム）で使っていた単価表データが、そのまま「現場マスター」の元データとして使えるとご指摘いただいた。

**既存データの所在（確認済み）**：`scripts/price_data.json`（このリポジトリに既存）
- 86社分、`[会社名, 昼単価, 夜単価, その他単価]` の配列形式
- 例：`["㈱イワシタ舗道", 34000, 42000, null]`、`["㈱フェアロード", "4/1 40,000", "4/1 45,000", null]`
- 一部の単価欄に日付・電話メモ等の文字列が混在しており、フェーズ2でインポートする際は整形（数値化）が必要

## 提案されている現場マスターの構造

```
現場
├─ 現場名（会社名）
├─ 昼単価
├─ 夜単価
├─ その他単価
├─ 現場区分（土木／運輸／舗装／民間／公共／その他）
├─ 使用車種
├─ 備考
```

## 配車時の想定フロー

```
現場を選ぶ
　　↓
会社（現場）の単価が自動表示
　　↓
ダンプを選ぶ
　　↓
運転手を選ぶ
```

## フェーズ1との接続点

- フェーズ1で設計した`home_department`/`current_department`の考え方、状態マスタ、`NameTag`のレイアウトに余白を持たせた設計は、この現場マスター・配車機能をそのまま載せられることを意図している。
- `scripts/price_data.json`はフェーズ2着手時に、現場マスターへのインポート元データとして活用する（要データクレンジング）。

## フェーズ2着手時に確認すべきこと（暫定）

- 単価欄の文字列（日付・電話メモ混在）をどう扱うか（自動抽出か、手動で整形してから取り込むか）
- 「現場区分」の6分類（土木／運輸／舗装／民間／公共／その他）で過不足がないか
- 現場マスターと、フェーズ1の`home_department`/`current_department`（部門）との関係性の整理
